1. OPIS TECHNICZNY - dla osób znających się na aplikacjach
===============================================================================

ARCHITEKTURA TECHNICZNA:
Stack: FastAPI (Python 3.11) + Vanilla JavaScript, deployed na Render.com  
Frontend: Progressive Web App (PWA) z Service Workers, responsive design  
Backend: RESTful API z asyncio, scheduled data fetching, push notifications  

INTEGRATIONS & DATA SOURCES:
- RCB RSS feeds - Rządowe Centrum Bezpieczeństwa
- IMGW API - Instytut Meteorologii i Gospodarki Wodnej  
- Lokalne urzędy - 16 województw + major cities (Warszawa, Kraków, Gdańsk)
- Geolocation API - automatyczna detekcja lokalizacji użytkownika
- Web Speech API - Text-to-Speech z age-appropriate content adaptation

KEY TECHNICAL FEATURES:
- Real-time alert aggregation z multiple government sources
- Location-based filtering - dynamiczne źródła danych based on user coordinates  
- VAPID Push Notifications - background alerts even when app closed
- Parental Consent System - GDPR Article 8 compliance dla children <16
- Offline-first PWA - cached alerts, works bez internetu
- Multi-language - PL/EN/UA z localized emergency terminology

PERFORMANCE & SCALABILITY:
- Caching: 300s TTL dla alert feeds, CDN static assets
- Background jobs: 10min intervals dla data refresh  
- Error handling: Graceful degradation, fallback sources
- Security: CSP headers, input sanitization, secure VAPID keys

DEPLOYMENT & MONITORING:
- Render.com hosting z automatic deployments
- GitHub Actions CI/CD pipeline
- Environment variables dla API keys (OpenAI, VAPID)
- Structured logging z error tracking
- Health checks i status monitoring

2. OPIS DLA URZĘDÓW I DECYDENTÓW - administracja publiczna

"Bezpieczny Pomocnik" to pierwsza w Polsce aplikacja dostosowana SPECJALNIE
